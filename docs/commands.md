# Planned WhatsApp commands

- `!livre 16:00-18:00` — mark an available interval for the current local date
- `!ocupado 16:00-18:00` — mark an unavailable interval
- `!semana` — show the user's week
- `!livres` — show mutual free slots
- `!marcar` — start a session proposal
- `!aceitar <codigo>` — accept a proposal
- `!recusar <codigo>` — reject a proposal
- `!cancelar <codigo>` — cancel a session (permission rules to define)
- `!ajuda` — command help

Commands will be implemented only after user identity is securely mapped to a verified WhatsApp number.
